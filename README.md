# Static Website Hosting Project

## Project Overview
This project is a responsive static website developed using HTML and CSS as part of a Cloud Computing Internship project. It demonstrates how static web pages can be designed and deployed online using GitHub Pages.

## Live Demo
https://iamsrikanthk.github.io/static-website-project/

## GitHub Repository
[View Repository](https://github.com/iamSrikanthK/static-website-project)

## Objective
The objective of this project is to understand static website development and deployment using a cloud-based hosting platform.

## Technologies Used
- HTML5
- CSS3
- Visual Studio Code
- GitHub
- GitHub Pages

## Features
- Responsive design
- Clean and modern layout
- Navigation bar
- About section
- Services section
- Features section
- Technologies Used section
- Contact form UI
- Public deployment using GitHub Pages

## Project Structure
static-website-project/
- index.html
- style.css
- README.md

## Deployment Steps
1. Created the project in VS Code
2. Developed the user interface using HTML and CSS
3. Tested the website locally in browser
4. Uploaded the project files to GitHub
5. Enabled GitHub Pages
6. Deployed the website successfully

## Outcome
The project was successfully hosted online and made publicly accessible through GitHub Pages.
